# FRC Team 1014 — the Bad Robots 🤖

We're the programming side of **FIRST Robotics Competition Team 1014**, a single team serving all three Dublin City Schools high schools in Dublin, Ohio.
Every January we get a new game, and about six weeks later we have a robot. This org is where its code lives.

🌐 [dublinrobotics.com](https://dublinrobotics.com) · ▶️ [YouTube](https://www.youtube.com/@Team1014/videos) · 📊 [Team 1014 on The Blue Alliance](https://www.thebluealliance.com/team/1014)

## Where to start

| Repo | What it is |
|---|---|
| [**BadRobot2026**](https://github.com/BadRobots1014/BadRobot2026) | Current robot code: Python / RobotPy, swerve drive |
| [ExampleSwerve](https://github.com/BadRobots1014/ExampleSwerve) | Minimal swerve example for learning and testing |
| [PicoLights2026](https://github.com/BadRobots1014/PicoLights2026) | Raspberry Pi Pico LED controller for the robots |
| [1014-sign-lights](https://github.com/BadRobots1014/1014-sign-lights) | Firmware for the team sign's lights |

New to the team? Start with the [**Team Wiki**](https://github.com/BadRobots1014/pybase-2026/wiki). It covers setting up your environment, how our codebase is organized, and how to make your first contribution.

## Past seasons

Every season gets its own repo, named `BadRobotYYYY`. The year is the competition season, which runs January–April, so `BadRobot2026` is the 2025–26 school year.
Older seasons are archived but still public. Browse them for ideas, or just to see how far we've come.
Our history goes back to [2012](https://github.com/BadRobots1014/BadRobot2012).

## Using our code

You're welcome to read, fork, and borrow from anything here.
It's built for our robots, so expect hardcoded ports, team-specific constants, and the occasional breaking change mid-season.
If something here helps your team, we'd love to hear about it.
